# TransVerse

**Браузърна мултиплейър транспортна и икономическа симулация върху реалната география на света.** Основи транспортна компания, поемай поръчки между реални градове, карай по реални пътни маршрути за камиони и се състезавай с други играчи в общ, постоянен свят.

## Какво работи (проверено с тестове)
- **Старт като самостоятелен шофьор** с нает камион (наем от всеки курс, без гориво и сервиз); **основаване на компания** при ниво 2, 3 доставки и 5 000 €.
- **Игрово време:** курсовете траят от 10 минути до 2 часа според разстоянието.
- **Обучение** в 6 стъпки за нови играчи.
- **Админ панел** с длъжности Основател/Главен администратор, Администратор, Техническа поддръжка; одит дневник; **раздел „Поддръжка“** със запитвания.
- Публична начална страница с реални данни от базата и реални маршрути.
- Регистрация, вход, изход, смяна на парола; argon2id; сесии в PostgreSQL; защита на `/game` и API.
- **Реална география:** 9 държави, 2 179 града (GeoNames), 97 пристанища, български имена; интерактивна карта (MapLibre + OpenFreeMap).
- **Реални маршрути за камиони** (Valhalla/OSM): разстояние, време, тол, точни гранични преходи; кеш; ясно обозначена приблизителна оценка при недостъпност.
- Общ товарен пазар; поемане от точно една компания; доставки по разписание с EU правила за почивки и гранично чакане; уреждане **точно веднъж** от фонов worker, независимо от браузъра.
- Автопарк: 6 модела превозни средства, 6 вида ремаркета, съвместимост, покупки/продажби, ремонт, подобрения, прикачване на ремаркета, капацитет на депата.
- Служители (шофьори с умения и растеж), заплати, обезщетения; депа в реални градове.
- Финанси: идемпотентна счетоводна книга, паричен поток, категории.
- Прогрес: нива, опит, репутация, 10 постижения; сезони с класации и награди без нулиране на активите; класации само на реални играчи; известия на живо (SSE).
- Оригинални SVG илюстрации на камиони и ремаркета в реален мащаб.

## Частично или предстоящо
- Партньорства, алианси, съвместни компании, търговия между играчи — не са реализирани (архитектурата с общ пазар и компании позволява добавяне).
- Кредити, лихви, данъци; други видове служители (диспечери, механици); умора и характер на шофьорите.
- Потвърждение на имейл и възстановяване на парола (нужен е имейл доставчик).
- Многоезичност: текстовете са на български в компонентите; форматирането е централизирано (`src/lib/format.ts`), но речници за други езици още няма.
- Маршрутизацията ползва публичния сървър на FOSSGIS — за голям трафик е нужен собствен Valhalla (виж `docs/DEPLOYMENT.md`). Пътните такси са игрова оценка на км, не реални тарифи.

## Бърз старт (разработка)
Нужни: Node.js ≥ 22, pnpm, PostgreSQL 16.
```bash
pnpm install
cp .env.example .env            # задай DATABASE_URL
createdb transverse && createdb transverse_test
pnpm db:migrate && pnpm geo:import && pnpm db:seed
pnpm dev                        # http://localhost:3000
pnpm worker                     # в отделен терминал — постоянният свят
```

| Команда | Описание |
|---------|----------|
| `pnpm test` | Интеграционни тестове (Vitest + PostgreSQL, база `transverse_test`) |
| `pnpm e2e` | Playwright тестове срещу работещ сървър |
| `pnpm check` | typecheck + lint + тестове |
| `pnpm build` / `pnpm bundle` | Продукционен build / bundle на worker и скриптове |
